Run it yourself

Elysium is open source. There is no sales call between you and a working instance.

It ships with a worked example — two SQLite silos, an ontology over them, three users with different grants — so the first question you ask returns a real answer and the second one gets refused for a real reason.

What you need

  • Python 3.12 or later.
  • Node.js 22.22.2 or later, for the front end.
  • Ollama, running locally, and enough free RAM for whichever model you choose. Nothing leaves your machine.

The short version

git clone https://github.com/nmartin0/elysium
cd elysium
# INSTALL.md has the full version, including the service install
# and how to keep the mirror in sync

The source and INSTALL.md are the authority; this page is a summary and will go stale before they do.

What you are getting into

A worked example, not an empty shell

The repository ships fixtures, an ontology, a policy with three users and a set of example questions. You are not writing YAML from a blank file to see whether it works.

Your data never leaves

Models run locally through Ollama and the mirror lives in your own deployment. Nothing is sent to us, and there is nothing to send it to.

One process, one organisation

A server instance runs one organisation's data, in one OS process. Running two workers against one deployment is not supported.

If something is wrong

Open an issue. Security reports go to the address in security.txt rather than a public issue.
