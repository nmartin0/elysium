Accessibility

What this site and the Elysium application do today, and what has not been audited.

Target: WCAG 2.2 level AA. No third-party audit has been carried out, so this is a statement of what is built rather than a conformance claim.

This site

  • A skip link to the main content on every page.
  • A visible focus ring at 2px against the page, not a hairline that disappears into a border.
  • Every image either carries alternative text or is marked decorative.
  • The architecture diagram has a written description of what it shows, in sentences, not a label.
  • Motion respects prefers-reduced-motion.
  • Text reflows to a 390px viewport without horizontal scrolling.
  • No colour is the only carrier of meaning.

The Elysium application

  • The object search results implement the ARIA grid keyboard contract: one tab stop for the whole list, arrow keys to move within it, Home and End to the ends. A hundred results is one Tab press to pass, not two hundred.
  • Keyboard focus is visible throughout and never trapped.
  • Colour contrast meets AA for text in both the light and dark themes.

Known gaps

  • No screen-reader testing with JAWS, NVDA or VoiceOver has been done.
  • The roving-focus contract covers the results list; other lists in the application have not been converted.
  • No automated accessibility suite runs in CI yet.

Reporting a barrier

If something here or in the application is unusable for you, say so and it will be treated as a defect rather than a request.
